# BuddyScript — Social Feed

A full-stack social feed application built from the provided BuddyScript design:
authentication, a protected feed with text/image posts, likes, comments,
replies, and public/private post visibility.

**Stack:** React 19 (Vite + TypeScript) · NestJS · PostgreSQL (TypeORM) · JWT in httpOnly cookies

Setup instructions, architecture and decisions are documented at the bottom of
this file as the project progresses.
